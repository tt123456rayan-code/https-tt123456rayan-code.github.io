## ⚙️ إعدادات لازم تعدلها قبل النشر — ملف `assets/app.js` (أول سطور)

```js
var CONFIG = {
  whatsapp: "962792669090",   // ✓ مضبوط (0792669090 بصيغة دولية)
  email: "info@hisnjo.tech",  // ← إيميل الاستقبال
  web3formsKey: ""            // ← مفتاح مجاني من web3forms.com
};
```

- **whatsapp**: ✓ مضبوط على 0792669090 — كل أزرار الواتساب بالموقع بتقرأ من هون.
- **إنستغرام**: ✓ مربوط @hisn_jo بالفوتر وصفحة التواصل.
- **web3formsKey**: سجل مجانًا على [web3forms.com](https://web3forms.com) بإيميلك، خذ الـ Access Key وحطه هون — نموذج التواصل بيصير يبعتلك مباشرة. إذا ضل فاضي، النموذج بيشتغل بوضع mailto كخطة بديلة.
- **إيميل الدومين**: فعّل `info@hisnjo.tech` مجانًا عبر Cloudflare Email Routing أو Zoho Mail.
